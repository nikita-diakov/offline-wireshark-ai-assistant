# Report Template

This is a reference outline for generated reports.

- Capture metadata (capinfos)
- Protocol hierarchy (io,phs)
- Top endpoints (IP)
- Conversations (TCP/UDP)
- DNS queries (subset)
- HTTP requests (subset)
- TLS SNI (subset)

Notes:
- Keep reports compact to improve LLM retrieval quality.
- Consider removing internal hostnames/domains before sharing.
